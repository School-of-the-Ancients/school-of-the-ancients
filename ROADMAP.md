# School of the Ancients roadmap

School owns teaching, mentors, lessons, assessment and learner records. Matrix is an optional world/exhibit runtime, not a prerequisite for School to work.

## Now

Finish and polish one useful historical-mentor lesson in the existing text-first School implementation.

Target loop:

```text
choose mentor -> explanation -> prediction -> interact -> discuss result -> follow-up -> save/resume
```

Keep the lesson usable with Matrix, voice and avatars disabled. Optional integrations must fail honestly without breaking the lesson.

Current priorities:

- preserve the existing Galileo/scale lesson and durable records;
- finish the useful parts of the open speech/visual work;
- keep the optional Matrix demonstration path reviewed and receipt-backed;
- make another person able to start and resume the lesson easily.

## Next

- better learner voice input and routing;
- mentor speech/captions/presentation;
- prepared exhibit packages;
- reusable Matrix-powered demonstrations;
- more mentors/lessons based on actual learning needs.

## Later

- World's Fair style exhibit library;
- adaptive curricula and learner knowledge models;
- shared/multiheadset learning;
- richer avatars/embodiment where it improves teaching.

## Boundaries

School owns:

- teaching policy;
- mentor profiles and grounded historical interpretation;
- lessons/curriculum;
- learner input and assessment;
- learner records.

Matrix owns:

- world execution;
- scene/content creation;
- Operator;
- physics/interactions;
- AI Citizens;
- world persistence.

A School mentor may be embodied in Matrix, but School learner records and Citizens memory remain separate.

## Work-selection rule

Keep one current user-visible School slice. Put detailed acceptance in the issue/PR being worked. Do not recreate a second School roadmap in the organization coordination repository.
